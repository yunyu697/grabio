# 对比度实测（v2，按当前 token 重算）

- 脚本：[tools/Check-FwContrast.mjs](../../../tools/Check-FwContrast.mjs)
- 取值来源：`src/styles.css` 的 token 定义（明暗 × 四套配色），不是设计稿或旧发布说明
- 判定：正文类 < 18.5px 要求 4.5:1（WCAG 2.1 AA），图标/图形 3:1；半透明底先按父层合成，渐进取更差一端
- 复跑：`node tools/Check-FwContrast.mjs`（不达标退出 1）、`--md`、`--json`

结论：8 套配色 × 24 个检查项全部达标，0 处低于阈值。11px 小字最低 4.57:1（明/azure 的选中导航强调文字），其余 11px 均在 4.59:1 以上。
