# 产品命名决策：Fetchweir → Grabio

记录改名前的查重口径、结论与被排除的备选，便于以后追溯「为什么叫这个名字」。
查重时间：2026-11-15。

## 查重口径

| 维度 | 口径 | 为什么这样取 |
| --- | --- | --- |
| 域名是否注册 | 注册局 RDAP 权威查询（Verisign `.com`、Identity Digital `.io`、Google Registry `.app`） | 本机 DNS 走代理，返回的是 198.18.x.x 假地址，`Resolve-DnsName` 的 NXDOMAIN 不能作为「可注册」的证据 |
| 域名是否在用 | 直接 HTTPS/HTTP 请求首页，取 `<title>` 与正文 | 区分「已注册且无站点」「已注册·停放页」「已注册·运营中」三种状态 |
| GitHub | `/repos/<owner>/<name>` 与 `/users/<name>` 状态码；`/search/repositories?q=<name>` 看全站同名仓库与 star | 用户名被占不影响 `owner/repo`，但影响「组织名/用户名同名」这条路 |
| 扩展商店 | Chrome Web Store、Edge Add-ons 搜索页逐名查询；Firefox 用 AMO `api/v5/addons/search` 并逐条比对 `name.en-US` 是否**精确相等** | 三处都是模糊匹配，只看「有结果」会把 grabber 类扩展误判成同名 |
| 包管理 | npm registry、PyPI JSON、crates.io API 的 404/200 | 404 才是可用 |

判定口径统一：**「已注册但无站点」与「可注册」分开写**；有同名产品在开发或已上线运营的单列。

## 备选为什么被排除

- **Haulio**：`haulio.io` 是运营中的物流/拖车平台（For Hauliers / For Shippers，英泰双语，带登录注册），三个域名全被占。
- **Fetchio**：`fetchio.io` 是运营中的在线文件工具站（转换/压缩/提取，beta），业务方向与「嗅探 + 下载」重叠；npm 与 PyPI 同名包已被占用。
- **Pullio**：GitHub `hotio/pullio`（98★）是活跃开源项目（容器自动更新），名字在技术圈已有归属；三个域名全被占。
- **Bytio**：`.com` 挂售、`.io` 于 2026-10 刚被注册，存在他人正在启动同名产品的可能。
- **Loadio**：虽然域名均无站点，但 npm `loadio` 已被占用，三个域名全被占。
- **Snagio**：查重结果最干净（用户名可用、`.io`/`.app` 可注册、三处商店与三个包源均无同名），是本次的第二选择；未采用仅因最终定名选了 Grabio。

## Grabio 的已知风险（已由用户确认接受）

1. `grabio.io` 于 2025-12 注册，首页为「Coming Soon / Something exciting is brewing — In development」占位页，说明有他人在做同名产品，方向未知。
2. `grabio.com`（2007 年注册）与 `grabio.app`（2026-10 注册）均已被注册，三处域名都拿不到；本项目不申请域名，只使用 GitHub 仓库与安装包名。
3. `github.com/grabio` 用户名被占，`yunyu697/grabio` 仓库名可用。
4. npm / PyPI / crates.io 与三处浏览器扩展商店当前均无同名，后续可注册。

## 文档中仍保留旧名的位置（有意为之）

- `docs/release-notes-v1.0.0.md` … `docs/release-notes-v1.1.0.md`：记录的是旧版本的历史产物与实际文件名，改名会篡改历史记录。
- `docs/evidence/**`、`docs/perf/**`、`docs/ui-shots/**`：历史实测原始数据，保持原样。
- `tools/Accept-Fw105-*.ps1|mjs`：针对 1.0.5 版的验收脚本，按旧路径/旧卸载项工作，属于历史工具。
- 工具文件名与参数前缀（`*-Fw*`、`-Fw`）：内部脚本命名，非产品品牌，不改以避免无意义的引用变动。
- Secret 名 `FW_SIGNING_KEY`：改名会导致已配置的密钥丢失，保持不变。
